
# 遊戲製作基準

  
## 遊戲長度 

所有遊戲皆以BPM 120為基準，一般長度為8拍(4秒)，長遊戲時間為16拍(8秒)。

All games should be based on 120 BPM,

and the game length should be 8 beats (4 seconds) or 16 beats (8 seconds) for longer games.

  
## 遊戲類型
遊戲類型可分為「動腦型」、「無腦型」、「節奏型」、「動作型」、--「獸控型」--，種類目前仍持續增加中。

Game categories are divided by "Brain", "Brainless", "Action", --"Furries"--, with new categories to be created.

  
### 「動腦型」
「動腦型」：通常為長時間遊戲，需要閱讀一段文字或圖片後，做出正確的選擇，其中帶有失敗條件。

ex：顯示長得相像的四個角色，但只有其中一個角色長的與三者不同，目標為選出長得不同的角色。


### 「無腦型」
「無腦型」：通常只需按下按鍵一定次數即可過關，且幾乎無失敗條件。

ex：顯示食物，且按6下即可吃完過關。
